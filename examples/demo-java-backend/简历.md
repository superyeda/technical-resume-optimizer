### 拼团营销系统 group-buy-market（个人实战项目） 2025.12 - 2026.06

技术栈：Java 8 ｜ Spring Boot 2.7.12 ｜ MyBatis ｜ MySQL 8 ｜ Redis / Redisson 3.26 ｜ RabbitMQ

- **DDD 三域建模与全链路交付**：按 DDD 划分 activity（活动/折扣）、trade（交易）、tag（人群标签）三个领域，设计并实现活动试算 → 锁单 → 支付回调 → 结算 → 组队通知完整业务链路，交付 6 个 Maven 模块、10 张数据库表、3 个 RPC 接口、4 个 Controller 与 17 个业务测试类。
- **策略路由树支撑营销试算**：基于策略路由树实现活动试算链路（Root → SwitchNode 降级切量 → TagNode 人群标签 → MarketNode 折扣计算 → EndNode），以策略模式实现满减/直减/折扣等优惠计算，支持营销规则灵活配置。
- **责任链 + 分布式锁保障并发一致性**：实现锁单与结算责任链过滤（活动可用性、用户参与次数、结算规则等），通过 bizId 唯一索引保证幂等，使用 Redisson RLock 分布式锁保障并发场景下的数据一致性。
- **MQ 异步通知与补偿兜底**：基于 RabbitMQ TOPIC 实现组队成功事件异步通知（EventPublisher + TeamSuccessTopicListener），设计 notify_task 任务表与 @Scheduled 每日补偿调度，保障回调通知不丢失。
- **自研 Redis 动态配置中心**：基于 Redis Pub/Sub 实现 @DCCValue 注解 + BeanPostProcessor + RTopic 监听热更新 Bean 字段，支持降级、切量、黑名单等配置动态下发，无需重启服务。
