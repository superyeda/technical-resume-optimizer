# ATS 与 PDF/HTML 检查清单

## ATS 内容

- 使用清晰的标准标题：职业摘要、工作/实习经历、项目经历、专业技能、教育经历、荣誉/论文。
- 将 JD 中真实具备的技能、职责和领域词自然写入摘要、经历/项目和技能区。
- 首次出现非通用缩写时，写全称加缩写；内部系统名需要补充类别说明。
- 禁止关键词堆砌，禁止列入无法在面试中解释的技术。

## ATS 版式

- 使用单列 HTML。
- 不让图片、图标、文本框或复杂表格承载关键信息。
- 保证联系信息、标题、经历、日期和技术关键词均为可复制文本。
- 保持日期格式、符号、大小写、项目符号和技术名称一致。

## PDF / 打印检查

- 使用 UTF-8 HTML 和中文可用字体回退：PingFang SC、Microsoft YaHei、Noto Sans CJK SC、Arial。
- 使用 `@page { size: A4; margin: ... }` 和 `page-break-inside: avoid` 保护经历模块。
- 检查最后一页没有孤立标题、单行 bullet 或大面积空白。
- 检查没有文字重叠、截断、乱码、横向溢出或链接不可读。
- 检查导出 PDF 后能搜索姓名、公司、岗位和核心技术词。

## 交付前最低标准

- 输出 Markdown、ATS HTML、现代 HTML、评估报告。
- 输出包含来源、置信度和待确认项的 Resume IR 与 source manifest。
- 增量模式输出变更报告，并保留前一版本。
