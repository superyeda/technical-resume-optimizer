# 中文技术简历排版规范

- 中文与英文、数字、技术名词之间加半角空格：`使用 Redis 缓存`、`优化 3 类 Key`、`P99 延迟 120 ms`。
- 技术名词按官方大小写：Java、Spring Boot、MySQL、Redis、RabbitMQ、Kubernetes、Claude Code、AOP。
- 日期统一使用 `YYYY/MM - YYYY/MM` 或 `YYYY.MM - YYYY.MM`，全篇一致；进行中的经历使用“至今”。
- 数字与单位加空格：`30 亿 Token`、`85% → 30%`、`120 ms`；百分号不加额外空格。
- 使用中文全角标点表达中文句子，技术栈可统一用 `｜` 或 `/` 分隔；不要混用英文逗号和中文顿号。
- 保持术语一致：模板，不写模版；AOP，不写 AoP；Claude，不写 Cluade。
- 姓名、手机号、邮箱均使用可复制纯文本，不用图片或图标承载。
